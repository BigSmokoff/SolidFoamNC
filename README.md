# 🛠 Плагин SolidFoamNC (nanoCAD + OpenFOAM)

Данный репозиторий содержит исходный код нативного NRX-плагина для nanoCAD, интегрирующего прочностной решатель `solidFoamNC` с графическим интерфейсом на базе **Qt 6**.

## Быстрый старт (Hot Start)

### 1. Требования к окружению

Перед клонированием репозитория убедитесь, что у вас установлены:

- **Visual Studio 2022** (с компонентом "Разработка классических приложений на C++").
    
- **nanoCAD SDK** (NC_SDK_RU_26.0.7228.4926.8429).
    
- **Qt 6.x.x** (Обязательно выберите компонент _MSVC 2022 64-bit_ при установке через Qt Maintenance Tool).
    

### 2. Настройка проекта после клонирования

Проект настроен на строгий стандарт **C++17** и использует специфичные флаги для совместимости ядра Qt 6 с legacy-кодом SDK nanoCAD. Все эти настройки уже вынесены в файл конфигурации.

1. Откройте `SolidFoamNC.sln` в Visual Studio.
    
2. Перейдите во вкладку **Вид -> Другие окна -> Диспетчер свойств** (Property Manager).
    
3. Разверните проект, найдите файл `SolidFoamSetup.props` в папке Debug x64 и кликните по нему дважды.
    
4. Перейдите в раздел **Пользовательские макросы (User Macros)**.
    
5. Измените пути в макросах на актуальные для вашей системы:
    
    - `QT_DIR` путь к компилятору Qt (например, `C:\Qt\6.9.3\msvc2022_64`)
        
    - `NCadSDK` путь к корню SDK nanoCAD (у вас должен быть после прохождения курса)
        
6. Нажмите ОК, выберите в студии конфигурацию **Debug | x64** и нажмите **Пересобрать решение** (Rebuild).
    

### 3. Запуск и отладка в nanoCAD

Если при загрузке плагина командой `APPLOAD` в nanoCAD возникает ошибка инициализации окна или жалоба на отсутствие платформенного плагина Qt:

- Скопируйте файл `qwindows.dll` (из папки `$(QT_DIR)\plugins\platforms`) в папку `platforms`, которую нужно создать рядом с исполняемым файлом `nmp.exe` (в корневой папке установленного nanoCAD).
